PROCEDURAL GALAXY · UNIVERSE SIMULATION

Four quadrants · 499 sectors per quadrant · procedural star systems and spherical worlds

Prototype · seeded generation · single-player preview

Universe seed

The seed makes this prototype's star positions and systems repeatable.

Simulation mode

Turn 1 · paused until advanced manually.

Navigation

Tap a star to select a system. In system view, tap a planet to inspect its generated world. Drag left/right and up/down to orbit the 3D view; scroll or pinch to zoom.

Selected object

Select a star in the galaxy to inspect its solar system.

Coordinates

Select a real star or a point on a planet to inspect coordinates.

Star catalog values are J2000 right ascension / declination. Procedural surface clicks report generated latitude / longitude, not real Earth geography.

Gravity simulation

1.00× gravity · Newtonian inverse-square model

Approximate game-scale N-body-inspired orbital model. It is not a precision ephemeris or a simulation of measured planetary masses.

World generation

Each generated planet is a 3D sphere with procedural surface colors, an orbit, a seeded type, radius, atmosphere, gravity, moons and a day length. The preview uses stylized procedural materials, not scientific terrain or live NASA ephemerides.

Planetary life engine

Select a planet to inspect its generated biosphere.

Stellar physics

Game-scale gravity and stellar properties are approximate; scientific catalog entries and generated values are labelled separately.

Multiplayer status

Offline prototype. Shared multiplayer requires the Rust authoritative server, MySQL persistence, authentication and WebSocket sessions to be deployed.

Controls

Drag rotate · Scroll zoom · click/tap select · use view buttons to change scale.

A browser-only page cannot provide secure shared multiplayer by itself. This page is structured as a client prototype for the planned server API.
